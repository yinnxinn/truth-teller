# 设计：让 skill 立体化——用「明朝朝廷机构」重建模内容流水线

> 状态：设计定稿（供审阅；**尚未落地为代码/SKILL 阶段改动**）
> 目标读者：想一起把它从"单条流水线"升级成"一家能运转的内容衙门"的人。

## 0.5 已定取舍（本节凝住，别漂）

1. **对外白话 / 内部 jargon**：拟旨/批红/封驳/复核这类称呼**只在内部流程与代码/批量产物里用**；
   对外（README、给用户看的提示文案、公众号脚注）一律白话（成稿/定稿/质检/核查…）。
2. **一个 SKILL 内按阶段切门禁**，不真开多进程/多 sub-skill；把分工做成"同一篇稿按阶段经过检查点"，稳、不乱。
3. **事实来源留痕触发式**：仅当素材涉新闻/财报/健康/法律等高风险时，强制产出《来源+认真脸》清单；
   平时轻量即可（保留"有出处就标、无出处不编"的下限，但不为每篇都做完整逐字分层）。

## 0. 一句话

现在的 skill 是一条直线：`素材 → 四刀拆 → 毒舌三段式 → 套模板 → 转 HTML → 存草稿`。
它本质是**一篇稿子的终结者**，不是**会做刊物的编辑部**。

要让它"立体"，我们不用在直线上加更多阶段，而是把它重建为一套**彼此制衡的朝廷机构**：
每道门有专司、每份稿先票拟再批红、每个纠错不和稀泥、每个决定都留成"批件"，并且**最终"批"字握在你——圣意——手里**（发表永远人工）。

## 1. 为什么要用「朝廷机构」而不是普通"流程"

明朝这套最值钱的不是单个机构，而是**互相制衡**：
- 写的人和批的人要分开（内阁票拟 vs 司礼监批红）；
- 批了也不是终点，有独立衙门能"封驳回去"（六科给事中）、能"察纪律"（都察院）；
- 重案再走一道"复核"（大理寺），避免写手自批自夸、一条道走到黑。

这三个动作对应一篇公众号稿子真正缺的东西：
**别自写自审、要有独立的"说不"、发外向前的来源复核。**

而它又天然贴合 skill 现有边界：**最高决断是你的**（对"毒舌"话术的取舍、以及"发表"这一下），机构再全 AI 也只是代拟 + 建议，不是代"批"。

## 2. 机构到职司的映射（合并你定的两块核心 + 我补充的承重）

| 朝廷机构 | 实际职权 | 对应到内容流水线 | 归属你点名的两块/承重 |
|---|---|---|---|
| **通政司/来折** | 收四方"事"，辨真伪民意 | **选题/素材门**——各方输入(老板信/财报/读者投稿/见闻)先收、先定性"值不值得做" | 上游选题 |
| **礼部 / 太常仪注** | 定格制、典章、文体格式 | **模板/体裁库**——定用什么"架式"(解构/翻案/教程/观点/清单…)，对应你要的**模板核心** | 模板（骨架） |
| **内阁（票拟）** | 拟旨、写作中枢 | **主笔/成稿**——真相官按选定骨架把素材写成拟旨（初稿） | 行文+风格核心 |
| **司礼监（批红）** | 对拟旨可否"代批"，管话语权 | **定稿/人情政治关**——这一版"像不像真相官该发的、戳不戳得住、有没有为效果牺牲边界"，决定能否进下一道 | 风格核心（守腔调） |
| **六科给事中（封驳权）** | 皇帝的批红也可"封还" | **质检/结构门**——错字、逻辑跳、长句绕、烂尾、红线上限，直接驳回去重改，不因"上面写过"放行 | 行文质检 |
| **都察院/监察御史** | 独立察纪律、纠弹 | **红线监督**——独立盯"是否攻击个人外貌/隐私/地域、是否把演绎当事实、是否越专业红线"，写手无权自己说了算 | 事实/边界承重 |
| **大理寺/按察复核** | 复核判案、再审事实 | **事实来源复核**（走向公开发布前的最后一道）——确认可核实事实有出处、健康/财务/法律是否给了"认真脸+劝更专业" | 事实承重 |
| **通政/存档（门下省档案）** | 登录在案 | **留痕/回溯源**——每阶段产物成"批件"存档(选题卡/来源清单/拟旨/封驳意见/定稿/发文记录)，供回溯与反哺 | 反馈回流的地基 |

## 3. 一篇稿子的"朝廷流程"（含门禁 gate 与产物留痕）

```
①通政司（来折）   → 一篇素材进府
    │   产物：素材登记 + 是否值得做（选题判断）
②礼部（择体裁）   → 定架式：解构 / 翻案 / 教程 / 观点 / 清单 / 来信回复…
    │   产物：选定的“骨架卡”
③内阁（票拟）     → 真相官主笔成稿（初稿：钩子→结构→判词，含黑话对照与认真脸位）
    │   产物：拟旨初稿.md；（并行）事实与来源.json（可核实/观点/演绎 分层）
④司礼监（批红）   → 可否：风格符不符、腔调稳不稳、有无为效果牺牲边界
    ├─ 打回 → 回③重拟
    ↓ 批红通过
⑤六科（封驳）     → 语言/结构/语气红线自审（长句、跳逻辑、烂尾、攻击个体…）
    ├─ 封驳 → 回③/④ 修正
    ↓ 通过
⑥都察院/大理寺    → 独立复核：事实有出处？红线无越界？专业话题“认真脸+不代答”？
    ├─ 弹劾/驳 → 回③补来源或删危句
    ↓ 通过
⑦样张呈现给你   →（圣意）你审，取舍措辞、决定是否可能发布
⑧礼部装帧+司礼监归档 → 微信安全校验 → 存草稿（全文”发表“仍是 ①→你手动）
    │   产物：终稿 html、校验报告、发文记录
⑨存档/御史交账     → 表现回填选题，下次少自重复
```

**铁律**（贯穿，别坏）：
1. **写与批分离**——同一个人(模块)不能既是主笔又是自己内容的定稿人；
2. **每个门都能"说不"**——六科封驳、都察院御史都是独立纠错，不走过场；
3. **事实优先于辞藻**——讽可以狠，每句刺都要戳在"可核实的问题结构"上，不能为痛快编来源；
4. **最终决断在你**——话术取舍、"是否发"都归"圣意"= 你，AI 只代拟与建议。

## 4. 和你要的两个核心 / 我补的第三承重如何咬合

| 你要的美点 | 落在哪座衙门 | 一句话做法 |
|---|---|---|
| **风格(voice)成核心** | 司礼监批红 + 范本锚点 | 把"基调一句话"升级成：红线清单(不能碰) + 腔调档(讽财报/教工具，同一个声音不同音量) + 经典成文当文风范本 |
| **模板(骨架)成核心** | 礼部仪注 + 体裁库 | 不止"毒舌三段式"，提供解构/翻案/教程/观点/清单多种骨架，并按素材自动路由 |
| **事实承重（我补的）** | 都察院 + 大理寺 | 来源三层标注、出处留痕、高风险题材"认真脸+劝更专业"，是地基层，防"编得有道理" |

> "风格=装修，模板=骨架，事实=地基承重；眼下最容易被忽略、却最不该省的是**地基(事实留痕)**——毕竟要做老板/员工/新闻这类公开发布的题材。"
