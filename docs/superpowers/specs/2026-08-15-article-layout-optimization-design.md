# 公众号文章版式与内容优化设计

## 目标

优化“AI不会先裁掉你，它会先把你打成一个分数”这篇草稿及后续同类文章的生成结果：去除展示日期，增加可传播金句，使用适量配图，重做结尾结构，并修复中文 UTF-8 编码问题。

## 设计

- 元数据中的日期仅用于归档，不再渲染到正文。
- 每个章节支持 `highlights` 金句列表，使用独立强调卡片渲染；正文保持短段落和较宽行距。
- 图片控制为最多 3 张：1 张主视觉，最多 2 张章节/中部插图。图片由文章数据显式指定，缺图时正文仍可正常生成。
- 结尾拆为“最后的判词”和“下期标题备选”两个独立模块。标题备选最多 3 条，不再用“建议标题改成”式措辞。
- 统一重写生成器中的中文字符串为 UTF-8，并以 UTF-8 读取/写入 JSON、HTML。

## 验证标准

1. 生成 HTML 中不出现 `2026-08-15` 或其他日期展示文本。
2. 生成数据包含 4 个章节、至少 6 条金句、最多 3 张图片。
3. HTML 包含主视觉/插图、金句卡片、独立判词和标题备选模块。
4. Python 编译通过，JSON 可用 UTF-8 正常解析，HTML 标题和正文中文可正确读取。
